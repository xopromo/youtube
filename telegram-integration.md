# 📱 Telegram Integration для YouTube Knowledge Base

## Что это даёт

Автоматический мониторинг Telegram-чатов с анализом сообщений через Claude:
- 🔔 Умные уведомления о новых видео, идеях, вопросах аудитории
- 🤖 ИИ-ассистент анализирует сообщения в фоне по расписанию
- 📊 Сводные дайджесты с ключевой информацией из группы
- 🔗 Автоматическая синхронизация контента из Telegram в Knowledge Base

---

## Быстрый старт

### 1. Создай Telegram-бота

1. Открой Telegram → найди `@BotFather`
2. Отправь `/newbot`
3. Назови бота: `YouTubeAssistantBot`
4. Юзернейм: `youtube_kb_bot`
5. Скопируй API-токен (выглядит: `7123456789:AAHxyz...`)

### 2. Добавь бота в чаты

Для каждого чата, где нужен мониторинг:
1. Добавь бота как **администратора**
2. Дай права: **читать сообщения, видеть информацию о членах**

### 3. Получи chat_id

**Способ А** — через @userinfobot:
- Добавь в чат, он пришлёт `chat_id`

**Способ Б** — через API в браузере:
- `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
- Напиши в чат что-нибудь
- Найди `"chat": {"id": ...}`

**Важно:**
- Личные чаты: положительные (`123456789`)
- Группы/супергруппы: отрицательные (`-1001234567890`)

### 4. Подключи Telegram MCP в Claude

1. Установи **Claude Desktop**
2. Settings → Plugins / MCP
3. Найди **Telegram MCP**, установи
4. Введи API-токен бота
5. Проверь: спроси Claude *"Покажи информацию о моём боте"*

## Сценарии использования для YouTube Knowledge Base

### 📌 Мониторинг новых идей

**Задача:** Каждый час читать сообщения в чате идей, выделить лучшие и добавить в `ideas/`

```
Читай последние 20 сообщений из чата [chat_id].
Выдели идеи с 3+ реакциями или упоминаниями.
Для каждой: отправь мне в личку краткую сводку.
```

### 🎬 Отслеживание вопросов аудитории

**Задача:** Каждые 2 часа ловить вопросы для новых скриптов

```
Проанализируй сообщения: ищи вопросы о здоровье, болезнях, YouTube-видео.
Если вопросов 3+ → отправь сводку с темами в личку.
Добавь в комментарий: "Спасибо за вопрос, планируем видео на эту тему!"
```

### 📝 Еженедельный дайджест

**Задача:** Каждый понедельник в 9:00 отправить сводку активности

```
Суммируй за неделю:
- Сколько новых идей предложено
- Топ-3 обсуждаемых темы
- Кто был активнее всех
Отправь в личку красивым форматом.
```

### 🔥 Вирусные идеи

**Задача:** Ловить идеи с потенциалом вирала

```
Ищи сообщения с ключевыми словами: "вирусное", "тренд", "просмотры", "конкуренты"
Если найдено + есть детали → отправь в личку с меткой [VIRAL_IDEA]
```

## Расширение: автосинхронизация с Knowledge Base

Когда идеи/вопросы получают достаточно реакций, Claude может:

1. **Создать файл** в `ideas/` или `analysis/`
2. **Форматировать** под структуру проекта
3. **Упомянуть источник** (Telegram, дата, автор)
4. **Отправить уведомление** о добавлении

**Пример:**
```
Если идея получила 5+ реакций → 
  1. Создать ideas/[тема]-telegram-[дата].md
  2. Добавить ссылку в README.md
  3. Отправить в чат: "✅ Идея добавлена в Knowledge Base!"
```

## Управление задачами мониторинга

### Расписания

| Интервал | Применение |
|----------|-----------|
| Каждые 15 мин | Активные чаты с срочными вопросами |
| Каждый час | Умеренная активность (вопросы, идеи) |
| 2 раза в день | Анализ трендов, еженедельные дайджесты |

### Отключение/переключение

```
# Отключить все задачи
Claude: "Удали все scheduled tasks для Telegram"

# Изменить расписание
Claude: "Измени мониторинг идей на каждые 30 минут вместо часа"
```

## Частые вопросы

**❓ Бот не видит сообщения в группе**
→ Проверь: добавлен как админ, имеет право читать сообщения, присутствует с момента начала мониторинга

**❓ API вернул пустой список**
→ Убедись, что в чате есть новые сообщения после добавления бота

**❓ Функция X не работает**
→ Telegram MCP поддерживает: текстовые сообщения, фото, отправку. Голос/видео — ограничение платформы.

**❓ Как автоматизировать добавление в Knowledge Base?**
→ Попроси Claude создать scheduled task с инструкциями по форматированию и файлам.
