# YouTube Knowledge Base

База знаний для работы с YouTube-каналами: сценарии, аналитика, аватары, идеи.

---

## Структура

```
youtube/
├── transcripts/              # Расшифровки видео (свои и чужие вирусные)
├── analysis/                 # Анализ крючков, структуры, удержания
├── scripts/                  # Готовые сценарии для видео
├── avatars/                  # Описания ИИ-аватаров (характер, голос, стиль, ниша)
├── ideas/                    # Идеи для видео, темы, гипотезы
├── telegram-integration.md   # 📱 Мониторинг Telegram-чатов через Claude
└── rules.md                  # Правила работы с базой
```

---

## Как использовать

### Добавить расшифровку
Файл в `transcripts/`, формат: `[тема-кратко]-[тип].md`  
Пример: `diabetes-9-symptoms-viral.md`

### Добавить анализ
Файл в `analysis/`, ссылается на источник в `transcripts/`  
Пример: `diabetes-9-symptoms-hooks.md`

### Добавить сценарий
Файл в `scripts/`, формат: `[канал]-[тема]-[дата].md`

### Добавить аватара
Файл в `avatars/`, одна карточка на каждый аватар

---

## Ключевые шаблоны (извлечены из анализа)

### Открывашка (медицина/здоровье)
1. Цитата пациента → разрыв ожиданий
2. «Сегодня расскажу о [N] признаках/способах...»
3. Анонс бонуса с интригующим ярлыком
4. Конкретная минута для досмотра
5. Представление через опыт (лет практики), не звания

### Блок одного пункта
1. Назвать → 2. Механизм (парадокс) → 3. История пациента → 4. Надежда
